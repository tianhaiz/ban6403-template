Module 3 Learning Goals

By the end of this lab, you should be able to:

  • write one small cleaning function and apply it the same way to every message;
  • explain what NFC and single-space cleaning change, and what they keep;
  • compare a light view and a lowercase view of the same text;
  • check what changed in the words a decision needs, and save that check as an audit table;
  • test cleaning rules on real complaints before anyone counts words.

The main idea: a cleaning rule is only good if the words the decision needs survive it. The original text always stays in its own column.

Part 1B: The Cleaning Function and Test Cases (Steps 1.8–1.14)

1.8 Write one small cleaning function

prepare_light does two things. First, NFC stores each character in one standard way. (Unicode is the standard computers use to store characters; NFC is one of its normalization forms.) Second, split() breaks the text on any whitespace and " ".join(...) puts it back with single spaces. The rule set is called light_v1.

def prepare_light(text):
    """Take one text and return it in NFC form with single spaces."""
    # Store characters such as é in one standard way.
    normalized = unicodedata.normalize("NFC", text)
    # split() breaks on any whitespace; " ".join puts the words back with one space.
    return " ".join(normalized.split())

What you should see

Nothing. The cell only defines the function.

Companion-added instructor note

What the function keeps

It keeps letter case, punctuation, numbers and words like no and not. It does not assign labels, remove HTML or fix spelling. Joining line breaks is fine for short messages, but it can break the layout of longer documents or tables.

2.10–2.11 Try deleting redaction tokens

A. Does cleaning twice change anything?

A good cleaning function gives the same result when you run it a second time. This is called idempotence. Expect 0.

# Clean the already cleaned text once more and count the rows that change.
cleaned_twice = audit["light_text"].map(prepare_light)
print("messages changed by a second cleaning:", audit["light_text"].ne(cleaned_twice).sum())

Result

messages changed by a second cleaning: 0

Companion-added instructor note

Checks have limits

Passing this check does not prove that the meaning survived. You still need to read the text.

B. NFC or NFKC?

NFKC is a stronger Unicode form. It also turns look-alike characters, such as the wide letters in TC04, into ordinary ones.

code_example = tests.loc["TC04", "text"]
# The same text in both Unicode forms.
print("NFC: ", unicodedata.normalize("NFC", code_example))
print("NFKC:", unicodedata.normalize("NFKC", code_example))

Result

NFC:  Code ＡＢ１２ failed.
NFKC: Code AB12 failed.

Would a product catalog want ＡＢ１２ and AB12 to be the same code? Decide before you use NFKC.
