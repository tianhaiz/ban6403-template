Module 7 Learning Goals

In this lab you test whether one sentiment score can tell a team what to fix. You score text with a sentiment lexicon (a word list with scores), then label aspects: the part of the product or service an opinion is about. By the end of the lab you should be able to:

  • Distinguish sentiment, product aspects and star ratings.
  • Compare a lexicon baseline, an embedding classifier and cached LLM labels against a reviewed sample of clothing reviews. Its labels were written against a short codebook.
  • Link an aspect and an exact evidence span to each judgment.
  • Report a pattern with its count and its denominator (the number of cases it comes from), and say what limits it.

The main idea: find what the opinion is about, and count with a denominator.

You do not call an LLM

An LLM (large language model) reads a prompt and writes text. Each text was sent to gemini-3.5-flash-lite once, with the temperature set to 0. Temperature controls randomness in the reply: 0 asks for the most likely answer. Even so, a rerun today could give some different answers. So every answer was saved, and you read those saved answers, which is called a cache. No API key is needed, and everyone evaluates the same labels. Step 1.8 shows what one saved answer contains.

1.5 Score a message with the lexicon

The helper splits the text into lower-case words and adds the valence of every word it finds. It flips the sign of a word when not, no, never, cannot or a word ending in n't appears in the three words before it. It misses forms without an apostrophe, such as didnt or dont.

NEGATORS = {"not", "no", "never", "cannot"}

def lexicon_score(text, negation=True):
    """Take a text; return its lexicon score and the matched words with their values."""
    # Lower-case the text and keep each run of letters and apostrophes as one word.
    words = re.findall(r"[a-z']+", text.lower())
    total = 0.0
    matched = []
    # enumerate gives each word together with its position i.
    for i, word in enumerate(words):
        # Words that are not in the lexicon count as 0, so skip them.
        if word not in valence:
            continue
        value = valence[word]
        if negation:
            # The (up to) three words before this one.
            before = words[max(0, i - 3):i]
            negated = False
            for previous in before:
                if previous in NEGATORS or previous.endswith("n't"):
                    negated = True
            if negated:
                value = -value
        total += value
        # :+.1f shows the value with its sign and one decimal, for example "help +1.7".
        matched.append(f"{word} {value:+.1f}")
    return round(total, 1), ", ".join(matched)

Now you use real customer reviews: the Women's E-Commerce Clothing Reviews in data/course/clothing_reviews.csv. Each review has a star rating, a recommend yes/no and a department. Domain mismatch

2.6 Weak labels from the star rating

A weak label comes from a cheap rule that is often, but not always, right. Here 1–2 stars become negative and 4–5 stars positive; 3-star reviews are left out.

# The weak-label rule. .map leaves 3-star reviews empty, because 3 is not in the dictionary.
STARS_TO_LABEL = {1: "negative", 2: "negative", 4: "positive", 5: "positive"}

2.7 Train an embedding classifier on the weak labels

The features are cached sentence embeddings of the reviews, made the same way as the Module 5 vectors. Logistic regression is a simple, widely used classifier. fit learns one weight per embedding dimension from the labeled train reviews. predict then gives the more likely label for reviews the model has not seen. This is the Module 4 discipline again: learn from train only, apply to valid. Module 8 covers the classifier in detail.

# One saved vector per review, in the row order of clothing_reviews.csv (as in Lab 5).
# The file stores compact 16-bit numbers; .astype("float32") turns them into ordinary numbers for the classifier.
vectors = np.load(DATA / "embeddings/clothing_minilm.npy").astype("float32")

# max_iter=1000 allows enough steps for the fit to finish.
clf = LogisticRegression(max_iter=1000)
# fit learns from the training rows only: their vectors (X) and their weak labels (y).
# vectors[is_train.to_numpy()] keeps the rows of the training reviews with a weak label.
clf.fit(vectors[is_train.to_numpy()], reviews.loc[is_train, "weak_label"])

# predict gives one label per validation review the model has not seen.
is_valid = reviews["split"].eq("valid") & reviews["weak_label"].notna()
valid_pred = clf.predict(vectors[is_valid.to_numpy()])
valid_weak = reviews.loc[is_valid, "weak_label"]
print("valid reviews, prediction equals weak label:", (valid_pred == valid_weak).sum(), "of", is_valid.sum())
print("majority baseline (always positive):", valid_weak.eq("positive").sum(), "of", is_valid.sum())

# row_of[review_id] gives a review's row position, which is also its row in `vectors`.
row_of = pd.Series(range(len(reviews)), index=reviews["review_id"])
# The row positions of the 120 reviewed reviews; vectors[reviewed_rows] keeps those rows in that order.
reviewed_rows = row_of[reviewed["review_id"]].to_numpy()
reviewed["clf_label"] = clf.predict(vectors[reviewed_rows])
print("reviewed sample, classifier equals reviewed sentiment:", (reviewed["clf_label"] == reviewed["overall_sentiment"]).sum(), "of", len(reviewed))

Companion-added instructor note

Selecting rows of an array

vectors has one row per review and one column per embedding feature. vectors[is_train.to_numpy()] keeps the rows where the mask is True, and vectors[reviewed_rows] keeps the rows at those positions. .astype("float32") turns the compact saved numbers into ordinary numbers for computing.
